# Design

Operate-mode darkroom. Lacquer ground, kinpaku gold as the only accent.

## Surfaces
- Lacquer: window chrome
- Lacquer deep: canvas well
- Raised lacquer: inspector rail
- Gold: live lasso, current cut, primary export
- Champagne: labels
- Muted: meta, inactive

## Rules
- One family: SF Pro. This is a Mac tool; system type is the correct Operate choice.
- 2px corners. No pills.
- Gold only for action, selection, and the lasso itself.
- No nested cards, no purple, no gray-on-gold text.
- Empty state is a dashed gold frame on the canvas, not a marketing illustration.
