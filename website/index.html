套索导出

套索导出是一款 macOS 原生套索圈选工具，用于把图片中的区域批量导出为 1:1 透明 PNG。 本地处理，无账号、无遥测，不上传素材。

下载 源码

简介

套索导出面向需要从整图快速切出多个正方形透明切片的人，例如 UI、游戏素材与表情包。 打开或拖入图片，沿轮廓画圈，选定画布边长后一次导出全部 PNG。

功能

套索导出提供徒手套索圈选、方图画布导出、画布缩放平移，以及仅本地读写的导出流程。

圈选

一圈一张，最后批量导出。

画布

边长 256 / 512 / 1024，可调边距。

操作

缩放、平移、撤销重做。

隐私

本地读写，可记导出目录。

步骤

使用套索导出只需三步：打开图片、画圈、导出。

  1. 打开图片 PNG / JPEG / HEIC / TIFF / WebP
  2. 画圈 一圈一张，可连续圈选
  3. 导出 选定画布边长，一次写出全部透明 PNG

常见问题

以下问题覆盖套索导出的定义、价格、开源、隐私、系统要求与导出位置。

套索导出是什么？

套索导出是一款 macOS 原生 AppKit 工具：打开图片后徒手套索圈选，再批量导出为 1:1 透明 PNG。

收费吗？

不收费。GitHub 完整版免费；Mac App Store 也计划免费上架，无内购。

开源吗？

是。源码在 GitHub（EvilIrving/lasso-cropper），MIT 许可。

会上传图片吗？

不会。图片只在本地读写；应用不发起网络请求。详见 隐私政策。

系统要求？

macOS 13 或更高。源码构建需要 Swift 6。

导出到哪里？

默认应用导出目录；可更换任意文件夹并记住授权。

和 Photoshop 有什么不同？

套索导出只做圈选与批量方图透明 PNG；Photoshop 是完整图像编辑套件，更重且通常付费订阅。
