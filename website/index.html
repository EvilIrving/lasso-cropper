圈一圈，导出 1:1 透明 PNG

套索导出是原生 macOS 工具：打开任意图片，沿轮廓徒手画圈，把每个圈选裁成正方形透明 PNG 并批量导出。 无账号、无遥测、素材不出机。

下载完整版 查看源码

功能

即圈即收

画完一圈自动收下，可连续圈多个区域，最后一次导出全部。

固定方图画布

导出边长可选 256 / 512 / 1024，边距可调，适合素材切片与表情包。

顺手的画布操作

滚轮缩放、触控板平移、空格拖动，撤销重做齐全。

本地与隐私

AppKit 原生，无网络请求。默认写到应用导出目录，也可授权任意文件夹并记住。

怎么用

  1. 打开或拖入 PNG、JPEG、HEIC、TIFF、WebP
  2. 沿轮廓画圈，每圈一张；可继续圈选
  3. 选好画布边长，点导出，一次写出全部透明 PNG

安装

GitHub 提供完整版免费下载与源码。Mac App Store 计划免费上架。 

git clone https://github.com/EvilIrving/lasso-cropper.git
cd lasso-cropper
./build.sh
open LassoCropper.app

需要 macOS 13+ 与 Swift 6。

常见问题

收费吗？

不收费。GitHub 完整版免费；Mac App Store 也计划免费上架。

会上传图片吗？

不会。读写都在本地，应用不发起网络请求，也不收集使用数据。

系统要求？

macOS 13 或更高。

和 Photoshop 比呢？

只做套索圈选与批量方图导出。没有订阅，启动更快，适合重复切素材。
