隐私政策

最后更新：2026-09-02 · 适用于「套索导出 / Lasso Cropper」macOS 应用

套索导出是一款仅在本机运行的 macOS 图片圈选工具：不收集个人数据，不上传图片，不发起网络请求，也不提供账号登录。

处理的数据

图片与导出

  • 打开或拖入图片时，应用在本地读取该文件以完成圈选与预览。
  • 导出时，应用在指定（或默认）文件夹写入 PNG。
  • 这些文件留在你的设备上；应用不会上传它们。

本地偏好

  • 画布尺寸、边距等保存在本机用户偏好中。
  • 自定义导出文件夹会保存安全作用域书签，避免反复授权。
  • 每张源图的圈选进度可能保存在本机 Application Support 目录。

不收集

  • 无账户、无登录。
  • 无网络请求（无分析、无广告、无崩溃上报）。
  • 不收集设备标识、通讯录、位置等信息。
  • 不把图片或导出结果发送到任何服务器。

权限

在 Mac App Store 沙盒下，应用只能访问你通过系统面板选择的文件或文件夹，以及应用容器内的默认导出位置。 可在应用内随时更换导出文件夹。

第三方

应用本身不嵌入第三方追踪或广告组件。 若你经由 GitHub、Cloudflare 或 Mac App Store 访问网页或下载，这些平台各自有独立隐私政策。

儿童

本应用不面向儿童收集数据，也不明知地向 13 岁以下儿童收集个人信息。

更新

隐私实践若变化，本页会更新「最后更新」日期。继续使用即表示知悉更新后的说明。

联系

隐私相关问题请通过 GitHub Issues 或 支持页 反馈。

隐私问答

收集个人数据吗？

不收集。无账号、无网络请求、无使用数据或设备标识采集。

会上传图片吗？

不会。图片与导出 PNG 只留在本机路径或应用容器内。

本机保存什么？

画布/边距偏好、导出目录书签，以及可选的圈选会话文件。
