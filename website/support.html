支持

套索导出 · Lasso Cropper · macOS 13+

套索导出的支持渠道以本页说明与 GitHub Issues 为主：可在此查看下载方式、系统要求、常见排查步骤，并提交反馈。

下载

套索导出可通过以下方式获取：

  • GitHub Releases：完整版免费下载
  • 源码仓库：自行构建
  • Mac App Store：计划免费上架（通过后将在此补充商店链接）

系统要求

套索导出需要 macOS 13 或更高；从源码构建还需要 Swift 6。

  • macOS 13+
  • 源码构建：Swift 6、Xcode Command Line Tools

排查

  • 打不开图片：检查 PNG / JPEG / HEIC / TIFF / WebP；改用打开面板
  • 导出失败：重新选择导出目录并授权
  • 找不到上次文件夹：再选一次导出目录
  • 构建失败：安装 CLT 后运行 ./build.sh

支持问答

如何获取？

GitHub Releases 免费下载，或克隆后 ./build.sh。App Store 计划免费上架。

系统要求？

macOS 13+。源码构建需要 Swift 6 与 Xcode Command Line Tools。

无法导出？

重新选择导出目录并授权；沙盒下必须对目标文件夹有写权限。

如何反馈？

到 GitHub Issues 提交，附上系统版本、复现步骤与截图。
