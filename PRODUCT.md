# Lasso Export / 套索导出

- **Audience:** designers and indie developers who split sprite sheets and icon atlases by hand
- **Job:** draw a freehand lasso around each object, then batch-export square transparent PNGs
- **Mode:** Operate. The canvas is the work. Chrome recedes.
- **Platform:** native macOS 13+ AppKit, not iOS
- **Distribution:** open source on GitHub first. Mac App Store is possible later with sandbox changes.
- **Not:** a chat app, a Between us feature, a template picker for one sprite sheet
